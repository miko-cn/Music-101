## 1. 为什么换掉蛇形图

路径页要回答的问题没变：**接下来做什么？** 规则也没变：当前关是第一个没掌握的关，四态仍是已掌握、上次没过、没做过、当前。

蛇形航道回答得太像游戏地图。折线、摆幅、霓虹描边都在争「这条路好不好看」，3 秒里看不清下一关。PR #7 把航道收成克制霓虹之后，隐喻仍是地图。用户已锁定：路径页改成教程目录，不是闯关地图。

Duolingo 在这里只借**单元列表**（一段标题，下面一排课），不借地图上的节点、路径和连线。

## 2. 目标与非目标

### 2.1 目标

1. 打开闯关首页，3 秒内能读完下一关的标题，并看到唯一的主按钮。
2. 27 关按三个阶段收成可展开的目录，阶段边界看得见，顺序扫得完。
3. 点任一关进行进入该关，和现在点路径节点是同一次导航。
4. 页面有轻微反馈：顶卡进场、目录展开、行与主按钮的悬停和按下。减动效时这些收成瞬时，功能不变。
5. 气质跟现有深色页面一致：主按钮最亮，其余是表面和文字，不像演示站。

### 2.2 非目标

- 不改 `pathStates`、`pathProgress`、`pathComplete`、`buildPath` 的判定。当前关仍是第一个没掌握的关；全部掌握时当前关仍是最后一关。
- 不改进度 schema，不把目录开合写进 localStorage。
- 不改关卡内容，不为摘要新开字段。一行摘要就是现有记忆锚口诀 `anchor.hook`。
- 不改双模式导航。闯关默认仍是这个首页；工具模式（乐理、诊断、记忆点、复习、进度）仍在旁边。关卡内顶栏文案仍是「返回路径」，路径页顶栏仍是「学习路径」。
- 不锁关。每一行都能点，和现在 `levelLocked` 恒为打开一致。
- 不做百分比。进度仍是「已掌握数 / 总关数」。
- 不做吉祥物。Miko、cheer、挂猫继续推迟，顶卡不留空位。
- 不恢复蛇形、折线、`layoutPath`、霓虹航道，也不把 PR #7 的 `--m101-path-accent` 青紫粉用回这一页。
- 不做整页视差、连线生长、节点呼吸、彩带。过关庆祝仍留在关卡内，不搬到目录上。

## 3. 信息结构

首页只有两块：顶上继续学，下面三阶段目录。

```
┌ 继续学 ─────────────────────────────────────┐
│ 接下来                                      │
│ 第 N 关 · 标题                              │
│ 一行口诀                                    │
│                              0 / 27         │
│                         [ 开始这一关 ]      │
└─────────────────────────────────────────────┘

┌ 01  阶段一 · 乐理地基            2 / 8    ▾ ┐
│  第 1 关 · 音高与键盘                       │
│  一行口诀                                    │
│  第 2 关 · …                                │
└──────────────────────────────────────────────┘
┌ 02  阶段二 · 编曲决策            0 / 12   ▸ ┐
└──────────────────────────────────────────────┘
┌ 03  阶段三 · 风格套路            0 / 7    ▸ ┐
└──────────────────────────────────────────────┘
```

关数以 `LESSONS` / `STAGES` 为准。阶段 id 与标题固定为：

| id | 标题 |
|---|---|
| `foundation` | 阶段一 · 乐理地基 |
| `arrangement` | 阶段二 · 编曲决策 |
| `style` | 阶段三 · 风格套路 |

### 3.1 顶卡「继续学」

数据来自现有路径函数，不另算一套「当前关」：

- 当前关：`buildPath` 结果里 `state === "current"` 的那个节点。全程恰好一个。
- 进度：`pathProgress` 的 `done / total`，写成 `{done} / {total}`。不用百分号，不加「关」字也能读；读屏名称里带上「已掌握」。
- 全部掌握（`pathComplete`）：kicker 用「全部掌握」，主按钮用「再看一遍」。否则 kicker 用「接下来」，主按钮用「开始这一关」。
- 标题行：`第 {id} 关 · {title}`。
- 摘要：该关 `hook`，一行，超出截断。
- 主按钮调用现有 `onOpenLevel(当前关 id)`。顶卡按钮不会写成「返回路径」。「返回路径」只出现在关卡页顶栏。

顶卡是这一屏唯一的重音。当前关在列表里还有一条轻标记，但不发光、不呼吸。

### 3.2 阶段手风琴

三个阶段按 `STAGES` 的顺序垂直排列。空阶段不渲染。

阶段头从左到右：

1. 序号 `01` / `02` / `03`（两位，从 1 计）
2. 阶段标题，用上表原文
3. `{本阶段已掌握数} / {本阶段关数}`。已掌握按该阶段节点里 `state === "mastered"` 计数。零也显示，折叠时看得到进度
4. 箭头：折叠朝右，展开朝下

含有当前关的那一个阶段，进入路径页时展开，另外两个折叠。点阶段头只切换这一段，不强制收起其他段。开合不记住；离开路径页再回来，恢复「只有当前阶段展开」。

阶段头是按钮。`aria-expanded` 反映开合，`aria-controls` 指向该段的列表面板。

### 3.3 关卡行

展开的阶段里，关按 `buildPath` 已有顺序排成左对齐列表。每行两行字：

1. `第 {id} 关 · {title}`
2. `hook`，一行截断

整行可点，调用 `onOpenLevel(id)`。不另做「仅标题可点」。

四态都在，但列表从轻，重音留给顶卡：

| 状态 | 行上看得见的东西 | 读屏 |
|---|---|---|
| `current` | 左侧 3px `--m101-brand` 色条，行底不变。不做浅底，也不发光 | 该行是当前步骤，并有「下一步」 |
| `mastered` | 行尾一个勾。不用大徽章 | 「已掌握」 |
| `retry` | 行尾一颗淡红点，直径不超过 8px | 「上次没过」 |
| `new` | 只有文字和分隔，没有点、没有勾、没有色条 | 无额外状态词 |

颜色不是唯一通道：勾和点是形状，当前关还有顶卡和读屏名称。`retry` 的红点用现有 `--m101-danger`，透明度保持能看清即可，不铺红底。

当前关若落在已折叠的阶段里（用户刚把该段收起），顶卡仍然指向它。展开该段后，当前行带上色条。

## 4. 视觉

跟现有深色页同一套表面，不新开一套霓虹色。

- 页底、卡片、文字、分割线用已经在用的 `--m101-bg`、`--m101-surface`、`--m101-text`、`--m101-text-dim`、`--m101-text-faint`、`--m101-line`。
- 主按钮是这一屏最亮的元素，用 `--m101-brand` 实底、深色字，按下沿用现有按压底边。不用 `--m101-path-accent`，不用阶段青、紫、粉。
- 顶卡：一块 `--m101-surface`，1px `--m101-line` 描边，圆角用 `--m101-radius-lg`。没有外发光，没有渐变灯管。
- 阶段头和关卡行：同一列宽，左对齐。行与行之间 8px 间距，行与行之间不再加分隔线。
- 当前行只用左侧 3px `--m101-brand` 色条，静止，不闪，不铺浅底。
- 窄屏下列表纵向排，不横向滚动，不出现轨道宽度。

PR #7 的航道视觉（蛇形、SVG 折线、阶段辅色连线、当前关柔光）在这一页退役。`--m101-path-*` token 若没有别的页面使用，实现时一并删掉，避免两套路径色并存。

## 5. 动效

目录要有反馈，否则会像一张静止的表。动效只做三件事：顶卡出现、一段目录打开或关上、行和主按钮对指针的反应。时长和缓动只取现有 token：`--m101-dur-fast`（140ms）、`--m101-dur-base`（220ms）、`--m101-ease-out`。不新写一条曲线，不用回弹弹簧。

产品规格里「只动 transform 和 opacity」在这一页保留，**手风琴面板的高度是唯一例外**。一段列表的开合没法只靠位移动完成，面板可用 `grid-template-rows` 在 `0fr` 与 `1fr` 之间过渡，时长 `--m101-dur-base`，缓动 `--m101-ease-out`。除此之外不被动高度、宽度或 top。

| 对象 | 做什么 | 时长 | 减动效 |
|---|---|---|---|
| 顶卡 | 进入路径页时透明度从 0.65 到 1，并上移 6px 后落定。只播一次，不循环 | `--m101-dur-base` | 直接以最终状态出现，无位移 |
| 阶段面板 | 展开、收起走上面的高度过渡。箭头用 transform 转到朝下或朝右，同一时长 | `--m101-dur-base` | 高度瞬时切换；箭头瞬时到位 |
| 刚展开的关卡行 | 每行透明度从 0 到 1，并上移 4px。第 i 行延迟 `i × 20ms`，延迟上限 200ms，超出的行跟最后一档一起出现。只在该次展开时播 | 每行 `--m101-dur-fast` | 不延迟，行直接出现 |
| 关卡行悬停 | 底色过渡到 `--m101-veil` | `--m101-dur-fast` | 颜色可以变，但不做位移动画 |
| 关卡行按下 | 向下 1px | `--m101-dur-fast` | 无位移，按下状态可以保留颜色 |
| 主按钮悬停 / 按下 | 沿用站内主按钮已有的悬停和按压底边，不另加光晕 | `--m101-dur-fast` | 无位移动画 |

不播：当前行呼吸、顶卡循环强调、折线绘制、阶段色闪烁、目录上的彩带。页面级 View Transition 继续负责换页；顶卡这 6px 是卡片自己的强调，不替代换页。

`prefers-reduced-motion: reduce` 时上表右列生效。开合仍然可用，只是没有过程。全局 motion 表里已有的减动效规则继续有效，这一页不靠「把时长写成 0」来假装还有动画。

## 6. 实现边界

实现时替换路径页的呈现，不重写进度规则。

- `App` 里闯关首页仍是现在这块区域，仍把 `progress` 和 `onOpenLevel` 传进去。
- 呈现改为顶卡加三个阶段。可以拆成继续卡、阶段、关卡行三个组件，但对外仍是路径页。
- 数据只用 `buildPath`、`pathProgress`、`pathComplete`。不调用 `layoutPath`，不读 `NODE_AMPLITUDE`、`NODE_WIDTH`、`NODE_HEIGHT`。
- `path-layout.ts`、蛇形几何测试、路径页上的 SVG 折线，在同一次改动里删除。它们没有第二个调用方。
- `tests/lesson/path.test.ts` 里节点状态、唯一当前关、进度用关数、阶段分组、每关有标题和口诀，这些断言留下。
- 路径页样式不再使用 `--m101-path-accent`、`--m101-path-accent-glow`、三个阶段辅色和 `--m101-path-surface`。
- 不新增吉祥物文件，不在顶卡或过关流程里接 Miko。

## 7. 成功标准

1. 路径页上看不到蛇形、折线、航道光晕。关卡是列表，不是地图。
2. 顶卡标题、口诀、`done / total`、主按钮与 `pathStates` / `pathProgress` / `pathComplete` 一致。全新进度时顶卡是第 1 关，「0 / 27」这种计数随实际关数变化。主按钮进入该关。
3. 含当前关的阶段默认展开，另外两段默认折叠。点阶段头能单独开合。再进入路径页时恢复这个默认，不记得上次手开过哪段。
4. 点任意关卡行进入对应关。从关卡回到路径，顶栏回到「学习路径」。工具模式入口仍在。
5. 四态在列表里可区分：当前有左侧色条，已掌握有勾，上次没过有淡红点，没做过没有装饰。顶卡比当前行更醒目。
6. 普通动效下，顶卡有一次入场，阶段开合能看见短过程，行和主按钮有悬停或按下反馈。减动效下无位移、无错峰、开合瞬时，按钮仍能用。
7. `npm test` 里路径语义测试通过；蛇形几何测试随布局模块一起移除，而不是改成永远失败。`npm run typecheck` 通过。

## 8. 和霓虹航道规格的关系

`2026-10-28-music-101-path-neon-redesign.md` 的视觉方案被本规格取代，包括蛇形幅度、阶段辅色、当前关柔光和顶卡霓虹边。该文档里的路径语义（当前关、四态、双模式、不用百分比）仍然有效，以本文件第 2、3 节为准。

Miko 的形象约束留在霓虹规格里，本轮不实现，也不把那些约束改写成目录上的装饰。
